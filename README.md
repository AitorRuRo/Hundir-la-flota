# Hundir la flota (actualmente, solo hay versión para PC)

Esta actividad la hice para aprender cómo "arrastrar" elementos con el ratón y entender cómo desarrollar por turnos un juego algo más complejo.

El enemigo solo tiene dos estados:
- Buscando: selecciona el "disparo" en una casilla aleatoria.
- Ataque: cuando encuentra un barco, ataca en las cuatro direcciones. Si en una dirección se bloquea, sigue buscando en las demás hasta que todas las direcciones sean agua.

Aquí gana el primero que hunda todos los barcos. He creado dos clases y cada una puede ser reiniciada.

## Barcos:
- 5 casillas (1)
- 4 casillas (1)
- 3 casillas (2)
- 2 casillas (1)

A la hora de la colocación de los barcos, los puedes girar con R.
